### 👩‍💻 Обо мне:

Я QA‑инженер с фокусом на тестировании API и интеграций. Помогаю командам выпускать качественный продукт: снижаю количество критических дефектов на проде за счёт проработки требований, раннего проектирования тест‑кейсов и системного регрессионного покрытия.

В работе использую Postman и SoapUI для REST/SOAP, Charles для анализа трафика, SQL и NoSQL для проверки данных, Kibana и Grafana для мониторинга. Базовые знания HTML/CSS/JS позволяют быстро локализовать дефекты и определить, где проблема — в API или в отображении.

Работаю в Agile: структурирую информацию, составляю тест‑планы и чек‑листы, готовлю подробные баг‑репорты и делаю процессы прозрачными для всей команды.

Открыта к предложениям на позицию QA Engineer (тестировщик). Если у вас есть вакансия, не стесняйтесь связаться со мной — буду рада сотрудничеству 🙌
